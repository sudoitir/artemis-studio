## 2026.09.41 — 2026-09-24

### Fixed

- **Align the settings section list to the start** ([9b1ca84e](https://github.com/sudoitir/artemis-studio/commit/9b1ca84e5589d6221224ddcd833cecf3ba42bda3))

  The section names in Settings were centred in their column, under group headings
  aligned to the start. They now line up with their headings, so the list reads as one
  column.

- **Show the change-password page after the first sign-in** ([09fbdc5b](https://github.com/sudoitir/artemis-studio/commit/09fbdc5bac8f74a2ef82daa68887e4106a97f1b1))

  Signing in with an account that must change its password (the generated
  administrator on first setup, for example) now opens the change-password
  page. Before, the browser was sent to /change-password and got a
  "Password change required" (423) problem instead of the page, because the
  lock covered the page's own HTML and scripts as well as the API.

  The lock now covers only the API, MCP, plugin screens and configuration
  refresh; the console shell loads so the password can be changed.

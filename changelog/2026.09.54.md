### Added

- **Give Studio a mark** ([7213f93e](https://github.com/sudoitir/artemis-studio/commit/7213f93ea7153553973030e8c7571cbbf1b009a5))

  Studio now has a logo, the crescent bow. Artemis' crescent moon is drawn as
  a bow, with one arrow flying into a single lit node: the queue that needs you,
  found across the whole cluster. It is the browser tab icon of the Studio
  console, which had none before, and it sits beside the product name in the
  console's header. It replaces the old mark on the documentation site and
  heads the README.

  The mark has one source file, web/public/favicon.svg. The site copies it at
  build time, as it already does for the screenshots, and a change to it
  rebuilds the site.
